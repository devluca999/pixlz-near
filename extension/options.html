With the Pixl Memory app installed you don't need anything here: the extension talks to it through Chrome's native messaging, and the app keeps the token. The token below is only for running the service without the app.

Pixl Memory

The extension saves highlights to the Pixl Memory service on this Mac. Nothing is sent anywhere else.

  1. Start the service: make -C memory serve
  2. Print the token: cd memory && uv run pixl-memory token
  3. Paste it below.
